# Калибровка (после монтажа, ~15 минут)

Все действия — из браузера на телефоне/ПК. Паттерны открываются НА ТЕЛЕВИЗОРЕ
(браузер ТВ или casting) по адресам `http://<pi>:8000/pattern/<имя>.png`.

## 0. Проверка кадра
Откройте `http://<pi>:8000/raw.jpg`. Экран ТВ должен помещаться в кадр целиком
с запасом по краям. Если углы срезаны — скорректируйте наклон/дистанцию камеры
(норма: 1.0–1.3 м от плоскости экрана).

## 1. Экспозиция
На ТВ откройте `/pattern/white50.png`. Через
`POST /camera/controls {"AeEnable": true, "AwbEnable": true}` дайте камере
подстроиться 3–5 с, затем считайте установившиеся значения из превью и
зафиксируйте их в `config.yaml → camera.controls` (AeEnable/AwbEnable: false).
ExposureTime держите 8330 мкс (кратно 60 Гц PWM подсветки — против полос).

## 2. Геометрия
1. На ТВ: `/pattern/geometry.png` (полноэкранно!).
2. `POST http://<pi>:8000/calibrate/geometry`.
3. Ответ: найденные маркеры и reprojection_error. Норма — ошибка < 2 px,
   маркеров ≥ 6. Проверьте `/preview.jpg`: экран должен стать ровным
   прямоугольником без трапеции.

## 3. Фотометрия
Для каждого слайда: открыть на ТВ `/pattern/<имя>.png`, затем
`POST /calibrate/photometric/<имя>`. Порядок:
`white100 → white50 → white20 → red → green → blue → black`
(black — при типовом вечернем освещении комнаты).
Завершение: `POST /calibrate/photometric/compute`. Норма gain_spread < 3.

## 4. Проверка
Белое поле на ТВ → подсветка равномерно белая по всему периметру
(верх не тусклее низа). Серый 50% → нет мерцания и полос.

## Перекалибровка
Нужна только при сдвиге камеры/ТВ — повторить шаг 2 (геометрию);
фотометрия обычно переживает небольшие сдвиги.
